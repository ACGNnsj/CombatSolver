# CombatSolver 0.47.2

## 简体中文

- 改善部分先打能力牌铺垫、再跨回合进攻的路线选择，并完善生成药水与免费用药的衔接。
- 感谢 [ltlly](https://github.com/ltlly) 提交的 [PR #138](https://github.com/Torch1230/CombatSolver/pull/138)：减少路线计算过程中的临时内存申请。
- 感谢 [linjianlin](https://github.com/linjianlin) 提交的 [PR #143](https://github.com/Torch1230/CombatSolver/pull/143)：修正部分开局弃牌选择和注能核心的首回合充能球预测，完善跨回合战损统计与路线衔接，并减少长路线收尾时的重复计算。
- 感谢 [fengzhenhong](https://github.com/fengzhenhong) 提交的 [PR #140](https://github.com/Torch1230/CombatSolver/pull/140)：修复战前预报可能异常中断，并导致本次游戏中后续预报持续失败的问题。
- 感谢 [s1f102500012](https://github.com/s1f102500012) 提交的 [PR #142](https://github.com/Torch1230/CombatSolver/pull/142)：修复部分第三方模组加载时，卡牌、遗物等内容被错误识别的问题。
- 感谢 [xhj66](https://github.com/xhj66) 提交的 [PR #139](https://github.com/Torch1230/CombatSolver/pull/139)：补充第三方玩法模组的回合开始与回合结束效果适配方式，具体效果仍需提供对应适配。
- 底部内存条改为分别显示“游戏占用”和“系统可用”，整条以物理内存总量为准，修正将两个数字误标为用量与上限的问题。

## English

- Improved some routes that play Powers for later-turn payoffs, along with chains that use newly generated free potions.
- [PR #138](https://github.com/Torch1230/CombatSolver/pull/138) by [ltlly](https://github.com/ltlly): Reduced temporary memory allocations during route calculation.
- [PR #143](https://github.com/Torch1230/CombatSolver/pull/143) by [linjianlin](https://github.com/linjianlin): Fixed some opening discard choices and first-turn Orb predictions with Infused Core, improved per-turn HP-loss tracking and route continuation, and reduced repeated work when finalizing long routes.
- [PR #140](https://github.com/Torch1230/CombatSolver/pull/140) by [fengzhenhong](https://github.com/fengzhenhong): Fixed a pre-combat forecast failure that could prevent further forecasts until the game was restarted.
- [PR #142](https://github.com/Torch1230/CombatSolver/pull/142) by [s1f102500012](https://github.com/s1f102500012): Fixed incorrect identification of some modded cards, relics and other content during loading.
- [PR #139](https://github.com/Torch1230/CombatSolver/pull/139) by [xhj66](https://github.com/xhj66): Added another way for third-party gameplay mods to provide adapters for turn-start and turn-end effects. Individual effects still require an adapter.
- The bottom memory bar now shows game usage and available system memory as separate figures, with total physical memory determining the full bar. The figures are no longer mislabeled as usage and a limit.
